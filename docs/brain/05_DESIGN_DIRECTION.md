# Lumora Design Direction

## Goal
Lumora should not look like a generic AI-generated SaaS dashboard.

## Product Feel
- Trading terminal
- Market intelligence cockpit
- Liquidity intelligence platform
- Serious, precise, data-first
- Dark analytical interface
- High information density

## Avoid
- Generic gradient SaaS cards
- Random shiny AI dashboard style
- Overly playful visuals
- Fake-looking metrics
- Unclear data source labels

## Visual Direction
- Deep dark base
- Purple identity, but controlled
- Cyan/green/red only for meaningful market signals
- Compact cards
- Strong typography hierarchy
- Dense but readable layouts
- Status-first labels: Live, Stale, Fallback, Demo

## Future Customization
Users should eventually be able to customize:
- Dashboard widget layout
- Active market
- Compact vs Pro mode
- Theme intensity
- Trader presets

## Preset Ideas
- Scalper
- Liquidity Hunter
- Whale Watch
- Swing Trader
- Paper Trading Practice
